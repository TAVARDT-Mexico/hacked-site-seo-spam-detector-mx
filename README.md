## Capacidades de Auditoria Forense y Deteccion de Hackeo

* **Inspeccion de Cloaking para Motores de Busqueda**: Identificacion de contenidos alterados dinamicamente para rastreadores como Googlebot.
* **Inyeccion de Spam y Enlaces Fraudulentos**: Deteccion de bloques de texto camuflados con CSS negativo e iframes no declarados.
* **Redirecciones Condicionales Forzadas**: Auditoria de saltos arbitrarios de trafico hacia sitios externos de dudosa reputacion.
* **Calificacion de Nivel de Compromiso**: Metrica tecnica de 0 a 100 con guia paso a paso para el retiro de codigo malicioso.

## Instalacion y Ejecucion

Requiere Python 3.8 o superior utilizando exclusivamente la biblioteca estandar.

```bash
git clone https://github.com/TAVARDT-Mexico/hacked-site-seo-spam-detector-mx.git
cd hacked-site-seo-spam-detector-mx
python seo_spam_detector.py ejemplo.mx
```

Para formato estructurado JSON:

```bash
python seo_spam_detector.py ejemplo.mx -json
```
